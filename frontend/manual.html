1What is ChatWithRepo?

ChatWithRepo turns any GitHub repository into a chat. Point it at a public repo (owner, name, and branch) and it fetches the source, indexes it into a searchable vector database, and lets you ask plain-English questions — "where is the rate limiter configured?", "how does the auth flow work?", "summarize this project" — and get answers grounded in the actual code, not a generic explanation.

2Who can use this

Anyone with a ChatWithRepo account and a GitHub repository they want to understand faster:

New contributors

Get oriented in an unfamiliar codebase in minutes instead of days.

Maintainers & reviewers

Quickly answer "where does X happen?" without grepping the whole tree.

Students & learners

Study real, production codebases by asking them questions directly.

Anyone evaluating a repo

Deciding whether to depend on, fork, or contribute to a project.

3How to use it

  1. 1 Create your accountSign up, then log in — you'll land on the Dashboard.
  2. 2 Add a GitHub token (recommended, from the Profile page)Not required to sign up, but almost always needed to actually index a repo — see the section below.
  3. 3 Click "Create Chat"Enter the GitHub username/organization, repository name, and branch (defaults to main).
  4. 4 Wait for indexingYou'll see live progress — fetching the repo, then indexing it for search. Larger repos take longer; you're dropped straight into the chat once it's ready.
  5. 5 Ask anythingArchitecture questions, "where is this implemented", how a workflow works, or a project summary — answers are grounded in the indexed source.

4GitHub access tokens — when and why

Indexing a repository means fetching its file tree and source files from GitHub's API — and GitHub rate-limits that API by how the request is authenticated, not by your ChatWithRepo account.

Without a token GitHub allows only 60 requests/hour, shared across every user hitting this app's server from the same location. That's rarely enough to index a real repository — most attempts without a token will hit the limit partway through.
With your own token Your limit jumps to 5,000 requests/hour, and it's yours alone — it doesn't affect, or get affected by, other users' activity.

How to add one: go to Profile → create a classic token with repo scope at github.com/settings/tokens → paste it in and save. It's used only to make GitHub API requests on your behalf.

If indexing fails with a rate-limit error, the message tells you exactly when GitHub's limit resets — but adding a token is the real fix, and it also unlocks retrying a failed chat: just reopen it from "Previous chats" once your token is saved, and it retries automatically.

6Repository support

A repository can be indexed as long as it's under 500 MB and 5,000 files (after filtering out non-source files like images, binaries, and lockfiles). Public repositories work with or without a token — private repositories require a Pro plan.

7Tips & troubleshooting

Indexing seems stuck

Large repositories can take a few minutes — watch the progress panel for the chunk count. It's still working as long as that number is climbing.

"Rate limit reached" error

Add a GitHub token in your Profile, then reopen the chat from "Previous chats" — it retries automatically with your new token.

A previous chat won't open

Tapping a chat that failed to index doesn't just show the old error — it retries first, so fixing the underlying issue (usually a missing token) and reopening it is often all you need.

Answers seem off

Make sure you're on the branch you actually meant to index — each chat is tied to one specific owner/repo/branch combination.

8Privacy

Your GitHub token is stored against your account and used only to make GitHub API requests on your behalf — to fetch repository content for indexing. It's never shared with other users or used for anything else. You can replace or remove it from the Profile page at any time.
